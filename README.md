# ml-cryptography
Supplementary code and data for the manuscript:  Machine-Learning-Guided Screening of bipartite graph distance cipher configurations.

## Repository Contents

- `ml_guided_graph_cipher.py` — Python implementation of the machine-learning-guided bipartite graph distance cipher framework.
- `README_ml_graph_cipher.txt` — supplementary description and usage information for the implementation.
- `requirements_ml_graph_cipher.txt` — Python dependencies required to run the code.

## Usage

Install the required dependencies using:

`pip install -r requirements_ml_graph_cipher.txt`

Then run the implementation using:

`python ml_guided_graph_cipher.py`

## Reproducibility

The source code and supporting files are provided to facilitate reproducibility and further evaluation of the computational methodology described in the associated manuscript.
